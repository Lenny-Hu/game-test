# 合成大西瓜 · Suika H5

单文件 Canvas 2D 网页版合成大西瓜，零外部依赖、零图片资源，11 档水果、玻璃罐、粒子/彩带全部程序化绘制，音效 Web Audio 实时合成。双击 `index.html` 即可玩，手机竖屏天然适配（竖罐布局）。

## 玩法规则

- 水果从罐口吊挂移动，**松手投放**；两个相同水果相碰即合成上一档更大的水果。
- **水果链（11 档）**与合成得分（新档位三角形数）：

| 档位 | 水果 | 半径比 | 合成得分 |
|---|---|---|---|
| 0 | 樱桃 | 0.176 | —（投放出现） |
| 1 | 草莓 | 0.232 | +3 |
| 2 | 葡萄 | 0.303 | +6 |
| 3 | 柠檬 | 0.366 | +10 |
| 4 | 橙子 | 0.423 | +15 |
| 5 | 苹果 | 0.507 | +21 |
| 6 | 梨 | 0.584 | +28 |
| 7 | 桃子 | 0.669 | +36 |
| 8 | 椰子 | 0.760 | +45 |
| 9 | 哈密瓜 | 0.845 | +55 |
| 10 | 大西瓜 | 1.000 | +66 |

- **连锁**：一次接触引发的级联合成在同一步物理内连续结算（上限 96 次），≥2 连弹「连锁 xN」飘字并奏琶音。
- **双瓜同归**：两个大西瓜相碰双双消除，**+100 分** + 彩带喷发（大西瓜不再产生，玩法为无限冲分）。
- **终局**：任一水果顶部越过罐口**危险线**并停留累计 2 秒即游戏结束（刚投放的 0.6 秒为宽限期；危险累积时红线闪烁、右侧显示危险进度条并每秒示警）。
- **三档难度**：只影响投放池的最高档位，其余规则一致；**最高分按难度分别记录**。

| 难度 | 投放池 |
|---|---|
| 简单 | 樱桃/草莓/葡萄 |
| 普通 | +柠檬 |
| 困难 | +橙子 |

- 投放冷却 0.45 秒；右上角预览「下一个」水果。最高分与难度选择存 `localStorage`（键 `suikabest` / `suikadiff`）。

## 操作

- **鼠标**：在罐口上方移动瞄准，**点击或按下拖动后松开**投放；**触屏**：按住拖动瞄准、松手投放。
- **键盘**：`←/→` 微调瞄准，`空格`/`Enter` 投放；菜单/结算界面 `Enter`/`空格` 开始或重开；`M` 静音。
- **中途退出**：对局中点左上角「菜单」按钮或按 `Esc`，随时退出回主菜单（当前得分自动结算进该难度最高分，局面清空），可重选难度再开局。
- 菜单点难度胶囊开局，上次难度自动记住；Canvas 内绘按钮均有点中判定。

## 技术要点

- **物理**：固定步长 1/120s；重力积分后每步做 5 次顺序迭代——墙/地板夹取 + 圆-圆位置修正（按半径平方加权、系数 0.85）+ 低恢复系数（0.05）法向冲量 + 切向摩擦；水果按水平速度滚动旋转。
- **合成判定**：圆心距 ≤ 半径和 + 2px 接触容差即合成（接触式判定，配合位置修正的自然堆叠刚好触发）；夹取在扫描前、新球生成时就地夹取，保证「同档接触必合成」无瞬态残留。
- **几何不变量**：任意步后所有水果必在容器内、同档接触对必已消除——由 `_test.js` 整局模拟逐步断言。
- **危险线**：位于罐口下方，越线检测带 0.6s 投放宽限与 2 倍速衰减，防误杀。
- 渲染：单 `<canvas>` 全屏，DPR 上限 2，逻辑尺寸以屏高 800px 为基准（`S = H/800`）；横屏收窄成竖罐，竖屏占宽 90%+。
- 音频：Web Audio 实时合成——投放下滑音、合成果音（音高随档位 1.16 倍递升）、连锁琶音、双瓜四音和弦、危险示警、终局下行锯波，无音频文件。
- 特效：果汁粒子环、白色合成闪光、双瓜彩带（36 片旋转矩形）、得分飘字、危险线脉冲。
