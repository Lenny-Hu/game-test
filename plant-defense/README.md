# 植物防线 · Plant Defense Line

经典玩法的草坪塔防网页版，单文件纯 Canvas 2D，零依赖、零外部素材。
行尸从右侧列队压来，玩家在 9×5 草坪上收集阳光、种下植物防线；
每行都有一台**一次性割草机**兜底——但只有五台，漏过就是永久的。

> 名称与美术均为原创程序化绘制，仅玩法致敬经典植物塔防品类（机制不受版权保护）。
> 若将来上架任何小游戏平台，请把名称/美术进一步差异化（避免他人注册商标）。

## 规则速览

| 项目 | 值 |
|---|---|
| 地图 | 9 列 × 5 行草坪，行尸自右边缘随机行入场，向左推房 |
| 割草机 | 每行 1 台（共 5 台）：行尸抵近触发，6 格/秒清整行，一次性；用尽后该行被渗透即败 |
| 关卡 | 3 关（晨光草坪 / 夜雾草坪 / 暮色屋顶），逐关解锁，通关即解锁下一关 |
| 波次 | 6 / 8 / 10 波，末波为大波；血量 = 难度 × 关卡 ×（1 + 5% × 波序） |
| 阳光 | 天降 25 光（间隔 9s × 难度系数）点击收集；阳阳葵每 20s 产一颗（首产 5s） |
| 经济 | 卡牌各自独立冷却（6~25s），铲子免费移除已种植物 |
| 计分 | 击杀 100/150/250 分 + 清波 25×N + 胜利按未触发的割草机 ×200 |
| 最高分 | 按 难度 × 关卡 九格存 localStorage（`plantdef_best` / `plantdef_diff` / `plantdef_unlock` / `plantdef_level` / `plantdef_seed`） |

## 操作

- 菜单：点难度胶囊与关卡卡（未解锁置灰防呆）→「开始游戏」或 Enter
- 选卡：点顶部卡槽（阳光计数器右侧）或按 1~5；再点草格种下；S 切换铲子、点植物移除
- 空格循环 1x/2x/3x 倍速，Esc 暂停，M 静音；对局中左上角「菜单」可随时退出（自动结算纪录）
- 触屏与鼠标统一 Pointer Events；手机竖屏自动切为图上、卡槽两行置下

## 技术要点

- 全部玩法随机（天降阳光位置、行尸入场行/延迟、植物摆相）走**种子 LCG** 并在开局重置，同种子重放逐位一致（视觉粒子仍用 Math.random）
- 固定步长 1/60s 模拟，倍速 = 每帧多跑步长；暂停跳过推进
- 行尸位置用「列」连续坐标表达（0~9.55），渲染时按当前布局换算像素，缩放安全
- 阳阳葵/阳光计数器在卡槽栏为独立槽位（`_meter`），不与 `pd_sun` 植物卡冲突
- 分数胶囊画在卡槽栏内、倍速/暂停/菜单圆钮下方（横屏 y 39~59U，竖屏同比例缩放）；绘制顺序固定为卡槽栏在前、HUD 在后，防止不透明栏底把分数盖住
- 植物、行尸、割草机、房舍、粒子、菜单/暂停/结算面板全代码绘制；音效 Web Audio 实时合成

## 回归测试

`node _test.js`（约 194 项断言，全绿输出 `ALL PASS`）覆盖：

1. 常量与数值表单调性 2. 三尺寸布局（横/竖屏） 3. 阳光经济（天降/产出/收集/寿命）
4. 种植·冷却·铲子·樱桃自毁 5. 战斗（索敌/命中/护盾/减速公式/啃食停走几何）
6. 割草机触发与清行、渗透判负 7. 樱桃爆伤半径边界
8. 波次调度（第 1 关总怪数 33、清波奖励、末波大波） 9. 同种子 60s 快照逐位一致
10. **贪心 Bot 整局必胜：3 关 × 3 难度固化种子重放** 11. 放任必败（320s 被推平）
12. 解锁链与 localStorage 持久化 13. 面板内按钮注册与真实点击流

樱桃按血量权重（铁桶 3 / 路障 2 / 其余 1）达 4 分起爆 → 波间屯钱转火力。
