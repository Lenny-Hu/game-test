# 弹弓怒鸟 · Slingshot Rage Birds

经典弹弓拆塔玩法的原创化网页版（名称、角色、美术全部原创程序化绘制，仅玩法致敬品类，
不含任何原作素材，规避版权风险见文末）。单文件 `index.html`，原生 Canvas 2D +
Web Audio 合成音效，零依赖、零外部请求，浏览器直接打开即玩，手机触屏通用。

## 玩法

拖住弹弓上的小鸟向后拉，松手发射；用飞行轨迹撞塌木头/玻璃/石头搭成的堡垒，
砸死或炸死所有绿猪即过关。每关限定鸟数，剩余鸟每只折算 10000 分。
共 12 关（初阵 → 琉璃屋 → 石哨塔 → 双塔连营 → 火药库 → 终局堡垒 → 云梯阁楼 →
玻璃温室 → 炸药仓库 → 双城记 → 孤塔凌霄 → 猪王要塞），过关即解锁下一关。

### 小鸟技能（飞行中点屏幕 / 按空格触发，每发限一次）

| 鸟 | 外形 | 特性 |
|----|------|------|
| 红兜 Red | 红色圆鸟 | 无技能，质量大、结构伤害 ×1.8，万能手 |
| 黄电 Chuck | 黄色三角头 | 触发后沿当前方向俯冲加速至 1.9 倍速（下限 520 px/s） |
| 蓝 trio Blues | 三只蓝色小鸟 | 触发后分裂成三路（±0.32 rad），专砸玻璃（质量小，对石木疲软） |
| 黑弹 Bomb | 黑色圆鸟带引信 | 触发后 0.45s 起爆；撞击速度 >150 也会在 0.15s 后自动起爆。爆速半径 118、强冲击 |

### 材料

| 材料 | 血量 | 受伤阈值（相对速度 px/s） | 特点 |
|------|------|------|------|
| 玻璃 glass | 24 | 95 | 脆，蓝鸟天菜 |
| 木头 wood | 55 | 150 | 中等结构件 |
| 石头 stone | 122 | 235 | 需重鸟高速或火药破 |
| 火药 tnt | 16 | 60 | 一旦被毁即引爆（半径 96），极易连环 |
| 猪 pig | 60 | 65 | 落地/被压也会摔伤 |

伤害公式：`伤害 = (接触相对速度 − 阈值) × 0.28 × 威力倍率`；无主坠落物倍率 0.5，
小鸟按各自威力 1.1~2.2。同一对物体每 0.25 秒只计一次伤害（防摩擦磨血）。

### 计分与星级

猪 +5000、碎块 +500、终局每只剩余鸟 +10000。
每关两档星级线（如猪王要塞 40000/62000），一星即解锁下一关。

### 难度（主菜单胶囊 1/2/3 快捷切换，持久化）

| 难度 | 鸟数 | 猪血 | 结构血 |
|------|------|------|--------|
| 简单 | +1 | ×0.8 | ×1.15（更厚=更耐砸但连锁更爽）|
| 普通 | ±0 | ×1.0 | ×1.0 |
| 困难 | −1 | ×1.3 | ×0.9 |

最高分按 `关卡 × 难度` 36 格分别记录（localStorage `ab_best_{关卡}_{难度}`）。

## 操作

- 主菜单：点难度胶囊 / 「开始游戏」（或 Enter）→ 选关面板点关卡卡。
- 对局：按住弹弓附近（叉心 150 px 内）拖拽瞄准，松手发射（拉距 ≤14 px 视为取消）；
  拉距半径钳制 92 px，且不允许拉到叉心右侧。飞行中点击/空格放技能。
- HUD：左上「菜单」回选关，右上暂停 / 重开 / 静音；Esc 暂停，M 静音。
- 结算：Enter 重开或进入下一关；「下一关」按钮仅胜利且非末关时出现。
- 触屏与鼠标统一走 Pointer Events；画面按 1000×620 设计空间等比 letterbox，
  手机横屏/竖屏都能完整一屏（无滚动）。

## 物理实现要点

- 自研刚体引擎：矩形×矩形用 SAT + 参考面/入射面线段裁剪（Box2D-lite 风格）取接触点，
  圆×圆、圆×矩形解析求解；法线统一归一为 A→B。
- 序贯冲量求解器 8 次迭代，累积并钳制法向/切向冲量（摩擦 √(μa·μb)），
  仅当接近速度 < −160 px/s 时启用恢复系数偏置（防静止抖动）。
- 位置修正 Baumgarte：先记录每个接触流形的最大穿深，再分 3 轮按剩余量递减分开
  （系数 0.6、余量 0.4 px），高塔堆叠沉降更小；每帧 2 个物理半步提高稳定性。
- 仿真随机（爆炸角冲量扰动、伤害冷却清理）走可复位的种子 LCG，每次 loadLevel
  重置种子——同一关卡 + 同一弹道序列必然得到同一结果（Bot 重放确定性的前提）；
  纯视觉粒子仍用 Math.random，不影响物理。
- 睡眠：速度平方 <225 且角速度小、持续 0.4 s 即冻结；唤醒只在新接触且
  接近速度 >90 且穿深 >0.8 时发生；破碎任意物体会全场唤醒以触发连锁坍塌。
- 低速阻尼（vx×0.93/帧）抑制圆柱/球的永转；飞出世界的残骸按消灭回收，
  settle 阶段带 2.5 s 硬超时兜底，保证回合一定轮转。
- 关卡用「顶/底面精确贴合」的坐标摆放（回归测试含初始零重叠审计），
  开局只有 ≤12 px 的一次性压入沉降（高塔稍多），随后全部进入睡眠，不会自塌。
