# 水果忍者 · Fruit Ninja H5（经典模式）

单文件 Canvas 2D 网页版水果忍者，零外部依赖、零图片资源，水果/刀光/特效全部程序化绘制。双击 `index.html` 即可玩，手机竖屏同样可玩。

## 玩法规则

- **90 秒限时**，目标是在时间内切出最高分。
- **三档难度**（主菜单选择，记住上次选择）：只影响炸弹的**出现概率、出现时机与单波数量**，水果得分与节奏完全一致：

| 难度 | 炸弹终局概率 | 开始出弹 | 单波最多炸弹 |
|---|---|---|---|
| 简单 | 8% | 25s 后 | 1 |
| 普通 | 18% | 15s 后 | 1 |
| 困难 | 32% | 8s 后 | 2 |

  概率为终局值，开局随时间线性升到该值。**最高分按难度分别记录**。
- **3 条命**：一个水果从屏底抛出后落出屏底未被切中，扣 1 命（底部红闪提示）；生命耗尽立即终局。
- **炸弹**：**切中炸弹直接终局**；炸弹自然落地无任何惩罚。
- **计分**：每切开 1 个水果 +10 分。
- **连击**：同一刀（按下到抬起）内切中 ≥3 个水果触发连击奖励，第 N 个额外 +10×N 分，并弹出「连击 xN」飘字。
- **最高分**：存 `localStorage`（键 `fruitninja_best`），破纪录在结算页显示 ★ 新纪录。

## 出波节奏（各难度一致）

| 时间段 | 出波间隔 | 每波水果数 | 炸弹概率（普通档示例） |
|---|---|---|---|
| 0–15s | 1.15s | 1–2 个 | 0 |
| 15–60s | 线性加快 | 2–3 个 | 线性升至 ~10% |
| 60–90s | 0.55s | 2–4 个 | 最高 ~18% |

## 操作

- **鼠标**：按住左键划动即挥刀；**触屏**：手指直接划动。
- 主菜单点难度胶囊（简单/普通/困难）后开局，上次选择的难度会自动记住。
- `Enter` / `空格`：开始游戏 / 再来一局；`M`：静音开关。
- 菜单与结算界面的按钮为 Canvas 内绘，点击命中判定。

## 技术要点

- 渲染：单 `<canvas>` 全屏，DPR 缩放上限 2；逻辑尺寸以屏高 800px 为基准（`S = H/800`），横竖屏/手机自适应。
- 主循环：固定步长累加器（1/60s）+ `dt` 钳制 50ms，标签页隐藏时 rAF 天然暂停。
- 切击判定：相邻两个 pointermove 采样点构成线段，与水果圆做「点到线段最短距离」相交测试，并对快速划动附加速度补偿半径。
- 物理：水果以「顶点高度随机」反解初速度上抛，重力恒定；切开后两半沿切面法线获得反向速度并带旋转。
- 特效：果汁粒子、屏幕溅渍贴花（上限 14 条自动轮换）、刀光拖尾（120ms 内渐细渐隐）、漏切红闪/炸弹白闪。
- 音频：Web Audio 实时合成（挥刀噪声、切果低 drum、连击三音上行琶音、爆炸噪声、漏切下滑音），无任何音频文件。
