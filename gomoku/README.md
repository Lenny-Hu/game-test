# 五子棋 · Gomoku（Canvas 2D 单文件）

15 路标准五子棋，纯原生 Canvas 2D + Web Audio，零依赖、零外部请求，双击 `index.html` 即可游玩。
标题栏、回合提示胶囊、按钮、计分板全部绘制在棋盘场景（canvas）内，不是 DOM 侧栏。

## 玩法与模式

| 模式 | 说明 |
|------|------|
| 双人对战 | 两名玩家同屏轮流落子（黑白两座位都是人） |
| 人机·执黑 | 你执黑先行，白方座位由电脑接管 |
| 人机·执白 | 电脑执黑先行，你执白 |
| 电脑演示 | 两个座位都由电脑接管，可暂停观察 AI 博弈 |

规则：无禁手自由规则，横 / 竖 / 双斜任一方向先连成 5 子及以上判胜；225 手满盘判平局。

## 开局菜单

进入游戏先到设置菜单（同样绘制在 canvas 场景内）：
- **游戏模式**：2×2 卡片四选一（选中金框高亮），下方一行说明当前模式的座位分配；
- **电脑棋艺**：三档单选，双人模式下整排置灰不可选；
- **开始游戏**：金色主按钮，确认后应用设置并开局（人机·执白会立刻让电脑走第一手）。

对局中按面板「菜单」或结算浮层「菜单」可随时返回设置菜单。

## 操作

- 点击棋盘交叉点落子；桌面端悬停有半透明预览子，光标随可落状态变化。
- 最后一手有红点标记；获胜连线金光脉冲动画 + 结算浮层（再来一局 / 菜单 两个按钮）。
- 面板按钮：悔棋（人机模式自动连带回退电脑一手）、重开、难度·三档循环、菜单；
  电脑演示模式额外有 暂停/继续 按钮。
- 快捷键：`U` 悔棋、`R` 重开（仅对局中生效）。触屏与鼠标通用（pointer 事件）。
- 战绩（黑胜 / 白胜 / 平局）持久化在 `localStorage['gomoku-stats-v1']`。

## 布局适配

`computeLayout()` 每帧按视口重算：
- 竖屏（高 ≥ 宽 × 1.02）：标题栏在上，15.2 格棋盘撑满宽度，按钮与比分在下方。
- 横屏：左棋盘右面板，按钮 2 列网格 + 提示信息区。
- DPR 缩放（`setTransform`），高分屏不发虚。

## AI 设计（三档棋力）

棋型打分 `lineScore()`：假设在候选点落子后，沿 4 个方向读取 9 格串型
（`1` 己方 / `0` 空 / `2` 对方或墙），按正则模式表取最高分：

| 棋型 | 模式示例 | 分值 |
|------|----------|------|
| 连五 | `11111` | 10,000,000 |
| 活四 | `011110` | 1,000,000 |
| 冲四（含跳冲四 `11011`/`10111`/`11101`） | `211110` 等 | 100,000 |
| 活三 | `011100`/`001110` | 60,000 |
| 跳活三 | `010110`/`011010` | 50,000 |
| 眠三 | `211102` 等 | 3,000 |
| 活二 / 跳活二 / 眠二 | `01100`/`01010`/`21100` | 800 / 700 / 150 |

候选点 = 已有棋子切比雪夫距离 2 内的空位（空盘取天元）。
单元格得分 = 己方进攻分 + 0.85 × 对手先落此点的分（防守略弱于进攻，倾向以攻代守）。

- **简单**：只用直线棋型表（看不到跳冲四/跳活三），保底会抓成五点，其余 35% 概率在 top5 随机（会漏防）。
- **普通**：完整棋型表贪心。
- **困难**：先查即成五 / 必堵五点，再对 top10 候选做一步前瞻（模拟落子后取对手 top6 反制的最劣值），2ms 级决策。

## 加禁手（连珠规则）的改造点

若要黑方禁手（三三/四四/长连），在 `play()` 落子前对 `st.turn === BLACK` 增加
`isForbidden(bd, x, y)` 判定即可，`lineScore` 已具备拆分棋型的读取能力。当前刻意不做，保持休闲规则。
