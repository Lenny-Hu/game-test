# 萝卜守卫战 · Radish Defense

经典玩法的塔防网页版，单文件纯 Canvas 2D，零依赖、零外部素材。
怪物沿土路走向终点的大萝卜，玩家抢在它们到达之前建塔拦截；
**没有怪可打时塔会自动清障**（拆石头/木箱/云朵），清开的空地既给金币又能当地基——这是本作的核心循环。

> 名称与美术均为原创程序化绘制，仅玩法致敬经典萝卜塔防品类（机制不受版权保护）。
> 若将来上架任何小游戏平台，请把名称/美术进一步差异化（避免他人注册商标）。

## 操作

- 点底部（横屏为右侧）面板选塔 → 点绿色格子建造；选中已建塔可升级/出售，同时显示范围圈
- 顶部 HUD：菜单 / 金币 / 萝卜生命 / 波次 / 得分；右侧 1x→2x→3x 加速与暂停
- 快捷键：`1/2/3` 选塔、`空格` 提前召唤、`S` 加速、`Esc` 暂停、`M` 静音；触屏与鼠标通用
- 手机竖屏自动切为「地图在上、建塔面板在下」，横屏为「地图居左、面板在右」

## 技术要点

- 全部 UI（HUD、建塔面板、升级弹窗、菜单、结算）画进 Canvas 场景内，无 DOM 控件
- 路径以格坐标拐点定义，敌人进度用 0~1 参数 `f` 表示——**resize 安全**，缩放不改变模拟
- 关卡数据（拐点/萝卜格/障碍/波次表/血量系数）集中在 `LEVELS` 数组，`selectLevel()` 热切换几何，波次推进与结算全部走 `curWaves()`
- 固定步长 1/60s；倍速 = 每帧多跑 N 个步长，暂停 = 跳过推进，逻辑与渲染解耦
- 子弹为追踪弹（存活帧校验目标引用），溅射结算遍历快照数组防迭代中击杀
- 怪物、塔、障碍物、粒子与音效全部程序化生成（Web Audio 合成），无任何外部请求
