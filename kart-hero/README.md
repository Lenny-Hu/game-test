# 菇侠卡丁车 · SHROOM KART RUSH

经典卡丁车竞速玩法的**原创化网页版**。名称、角色、赛道、美术与音效全部原创（程序化绘制 + Web Audio 实时合成），不使用任何第三方 IP 的名称、图形、音频与关卡数据，仅在玩法层面致敬竞速卡丁车品类。

- **单文件、零依赖**：全部逻辑在 `index.html` 内，无任何外部请求，双击即玩。
- **原生 Canvas 2D + Mode 7 伪 3D 追尾视角**：地平线、透视路面、深度缩放的广告牌精灵、车尾视角的自己的车——**全部画进 Canvas 场景内**，没有 DOM 弹窗与侧栏。
- **Web Audio 实时合成音效**：随转速爬升的引擎循环音 + 19 种一次性提示音，零音频文件。
- **两档脱困回位**：浅压路肩只在低速时管，整个车身被甩出赛道（含被撞晕）则不看车速约 1.2s 闪烁后摆回中线——回位只拉横向偏移，不送圈进度。
- **确定性**：影响玩法的随机全部走种子 LCG，固定 `1/60s` 步长，同种子重放逐位一致。

## 二、视角与渲染（Mode 7 伪 3D 追尾视角）

> 顶视俯拍视角下方向盘输入与画面位移不直观，「开起来不像赛车」。现在改成**车尾追尾视角**：物理、AI、道具、计圈、计分**一行没动**，只替换渲染层，所以 Bot 重放结果逐字节不变。

### 2.1 投影

赛道本来就是等弧长重采样的路点链，因此不必按扫描线做仿射贴图，直接对路点截面做**精确透视投影**（`proj(wx, wy, h)`）：

```
Z = dx·cos(camAng) + dy·sin(camAng)      // 沿视线深度
X = -dx·sin(camAng) + dy·cos(camAng)     // 横向偏移
iz = camFocal / Z                        // 屏幕缩放
sx = CW/2 + X·iz
sy = horizonY + (CAM_H - h)·iz           // h = 该点离地高度
```

三重剔除缺一不可：
- `Z < CAM_NEAR(14) || Z > CAM_FAR(1250)` —— 太近会畸变、太远没必要画。
- **视场角横向剔除**：环路另一侧深度完全合法却落在画面外几千像素，跨过去的四边形会拉成贯穿屏幕的黑色尖刺。
  > 但**剔除单位必须是「整个路面截面」而不是中心线单点**。路面截面的所有点（中心线 + 左右路肩 + 左右柏油边）都用 `proj(..., loose)` 跳过单点视场剔除，再取它们的屏幕跨度 `x0..x1`，只有 `x1 < -CW*0.5 || x0 > CW*1.5`（整条截面都在画面外）才丢弃。
  > 两个反面教材：① 按中心线剔 → 甩尾/急弯时中心偏出视场而路面还压在屏幕上，整块不画，表现为**跑过的赛道后面突然空白一块**；② 连边缘也剔 → 近处路面比视场宽得多，边缘被剔后四边形不成立，车头底下冒出「路面漏成草地」的洞。
  > 尖刺之所以不会回来：四边形只允许 `key` 相差 0.5 的两个**紧邻**截面配对（跨剔除缺口的配对被拒），而相邻路点世界间距只有 ~7.5px。
- 广告牌另加 `p.z < 78` 的**近区死带剔除**：落在「相机→车头」之间的东西会被透视急剧放大成一坨（刚喷出的尾焰粒子首当其冲），而这段视野本来就被自己的车挡住。

### 2.2 追尾相机（纯视觉，不参与任何判定，不消耗 `rng()`）

| 机制 | 做法 | 解决的问题 |
|---|---|---|
| 朝向滞后 | 目标角 = 车头角 + `clamp(速度方向偏差, ±0.6) × 0.34`，按 `rate = 11 + min(|lag|,1.6)×16` 指数逼近，再硬钳 `CAM_MAX_LAG = 0.42` | 漂移甩尾时相机滞后 → 侧滑感；滞后不封顶会把车甩到画面外 |
| 打转冻结 | `spinT > 0` 时目标角冻结为当前相机角 | 被道具打转时车头疯转，相机跟转会被甩到侧面 |
| 视线距离钳制 | 视线系 `vz ∈ [80, 112]` | 相机追位忽远忽近导致车身尺度脉动（`iz` 2.34↔3.6） |
| 横向偏移钳制 | 视线系 `vx ∈ ±CAM_DIST×0.3` | 急转时车滑到屏幕边缘（保留甩尾位移但不过界） |
| 侧倾 | `camRoll = clamp(speedL/640, ±0.2) + 转向输入×0.05` | 入弯时地平线跟着歪，是速度感的关键 |
| 自适应焦距 | `screenFocal() = max(CW×0.254, CH×0.40)`，提速时再 ×0.85 外扩视野 | 横竖屏都把车稳稳落在约 80% 屏高；竖屏手机也能铺满路宽 |

钳制后按视线分解的**精确逆变换**重建世界相机位置：`dx = vz·ca - vx·sa`，`dy = vz·sa + vx·ca`。

### 2.3 渲染分层

1. **天空**：地平线以上渐变 + 两层视差云 + 远/近山脊 + 日月（随朝向角视差移动）；night 主题额外有闪烁星野与缺角月亮。
2. **路面**：取可见路点截面（中心线 + 路肩各投影一次），**在世界空间**为相邻路点插入中点截面（位置/法线/高度都取平均后重新归一化）——屏幕空间取中点等于没细分。四边形按 `Z` 降序排序做画家算法，**分两遍绘制**：第一遍铺满所有地面明暗条带（每 4 段交替，速度感的主要来源），第二遍再画红白路肩 → 柏油 → 中线虚线，起点两格画棋盘线。
   > 为什么分两遍：单遍「一段地面 + 一段路面」交替画时，弯道会让远处那段路面折回到近段条带的 y 区间，被整幅宽的地面矩形啃掉一半，路面上就排出一排**拉链齿**。地面条带全部先画，层次冲突即消失（地形起伏只有 ±16，反过来穿帮不可见）。
3. **雾霭**：地平线附近一段渐变把远路面融进天空，拉开纵深。
4. **广告牌**：装饰物、道具盒、龟壳、香蕉皮、对手车、粒子、胎痕统一投影后按深度排序，尺寸乘 `iz`。对手车用 `squash = 0.42 + 0.58·|cos(heading - camAng)|` 横向压扁，否则侧身时也像是正对车尾。
5. **自己的车**：`drawKartRear` 的车尾 sprite 按真实投影绘制（会随甩尾在画面里横移），但不随地平线一起倾斜；`Z`/`X` 做温和钳制保证永不被裁掉。
6. **速度特效**：从消失点辐射的速度线（加速时 28 根 + 暖色暗角）、引擎尾焰、漂移三档蓄力火花、撞车震屏。

### 2.4 视觉起伏

`T.hgt[i]` 用环路的**整数倍频**正弦叠加（k = 3 / 5 / 8，幅值 8 / 5 / 2.5）合成缓坡，接缝处天然连续，且**不消耗 `rng()`**——这是确定性不被渲染改动打破的关键。幅值刻意压小：追尾视角里地形起伏会整屏推拉镜头，超过 ±16 世界单位就会把车顶出画面底边。

## 三、赛道

赛道由控制点闭环经 **Catmull-Rom 样条**插值后按 ~15px 等距重采样成路点链，每个路点预计算 `dir / nrm（法线）/ ang（朝向）/ radius（曲率半径）`，几何结果按赛道缓存（`getTrackGeom` / `trackCache`）。

| # | 赛道 | 半路宽 | 单圈基准秒（par） | 主题 | 装饰种子 |
|---|---|---|---|---|---|
| 0 | 菇菌环道 | 65 | 15 | meadow（草原） | 101 |
| 1 | 蜜糖峡谷 | 60 | 19 | candy（糖果） | 202 |
| 2 | 星夜高速 | 63 | 20 | night（星夜） | 303 |

三套主题各有独立的地面/路面/路肩/中线/天空配色，以及三种专属装饰物：

- meadow：`tree / mushroom / flower`
- candy：`lolly / cane / choco`
- night：`crystal / starbush / moonrock`

装饰物在路外 `halfW + WALL_OFF + 26 ~ +246px` 范围按种子随机散布（`rng() < 0.42` 跳过），只作视觉，不参与碰撞。

**道具盒布点**：从起点后第 46 个路点开始，每 ≥44 个路点取一行，且要求该行 ±3 路点窗口内曲率半径全部 ≥240（即只在直道/缓弯布点）；每行 3 个盒，横向偏移 `-0.44 / 0 / +0.44` × halfW。被吃掉的盒子 4.5 秒后复活（`BOX_RESPAWN`）。

## 四、物理模型（街机漂移）

固定步长 `STEP = 1/60`。速度按车头朝向分解为**前向 `speedF`** 与**横向 `speedL`**，横向靠抓地力衰减——这是漂移手感的来源。

### 4.2 关键机制

- **刹车/倒车**：`speedF > 10` 时按 `BRAKE` 减速；降到 10 以下转为倒车，按 `ACCEL × 0.6` 加速到 `-REV_MAX` 封顶。
- **漂移蓄力**：速度 ≥ `DRIFT_MIN_SPD` 且按住漂移键转向时进入漂移，抓地降到 `GRIP_DRIFT` 产生滑移；持续时长越过 `DRIFT_T` 三档门槛，松手即得对应档位 `DRIFT_BOOST` 的迷你涡轮。
- **墙体**：偏离中线超过 `halfW + WALL_OFF` 即被推回并做速度反射，损失 `WALL_LOSS`。
- **越野**：超出 `halfW` 但未到墙体的路肩外区域，极速压到 `OFF_VMAX` 并叠加 `GRASS_DRAG`。
- **打转**：被壳/星星/闪电命中触发 `spinOut`，持续 `SPIN_T`；`starT > 0 || invulnT > 0 || finished` 时免疫。打转后给 `SPIN_INVULN` 保护窗口，避免被连续收割。
- **卡丁车互撞**：`kartCollisions` 做圆碰撞分离；**无敌车撞非无敌车 → 对方直接打转**；普通互撞双方降速。
- **脱困回位**：分两档累计 `stuckT`，越过 `RESCUE_WARN(0.7s)` 整辆车开始闪烁，到 `RESCUE_T(2.0s)` 由 `snapToTrack` 摆回赛道中线。
  - **浅出界**（`lat > halfW - 8`，还在路肩带上）：要求合速度 < `RESCUE_SPD(105)` 才累计——高速压肩是正常跑线，不许打断。
  - **深陷困**（`lat > halfW + RESCUE_DEEP(6)`，整个车身已经跑到草地上）：**不看车速**、按 ×1.7 加速累计（约 1.2s 就回位）。这一档是专门为「被人撞晕甩出赛道」加的：撞飞之后玩家多半不敢按油门、或者在草地上把油门踩到底绕圈，两种情况都必须能自己回到赛道。
  - 回位只把**横向偏移**拉回中线，沿轨弧位原样保留（`clamp(fwd, 0, T.step)`），所以既绕不过计圈逻辑，也抄不了近道；**不动 `k.wp` / `k.lap`**、**不消耗 `rng()`**——九场 Bot 重放逐字节不变。
  - **油门意图只决定「回位后给不给 `RESCUE_POP(120)` 那一脚推力」，不决定回不回位**：没踩油门就原地停下（合速度 0），因此 §11「原地不动必败」依然成立；AI 恒视为有意图，避免 AI 卡死把整局拖到超时。
  - 打转期间（`spinT > 0`）计时**既不加也不减**：撞晕的那 1.15s 不该被浪费掉，出晕的下一刻就该接着闪烁回位。回位同时给 `RESCUE_INVULN(1.5s)` 无敌窗口，防止刚摆回来又被收割。

## 六、AI 与橡皮筋

- **循迹**：按路点前探 + 各自固定的车道偏移 `laneOff`（开跑时 `rng()` 决定，让 5 名 AI 走不同线路，不会挤成一列）。
- **弯速控制**：前探 26 个路点（步长 2）取最小曲率半径 `minR`，目标速度 `min(vmaxEff, sqrt(AI_LAT × max(60, minR)))`，其中 `AI_LAT = 620`（AI 过弯横向加速度上限）。超过目标 13% 才刹车。
- **橡皮筋**：`aiSpeedMul = 1 + catchup × clamp(gapLaps, -1, 1)`，其中 `gapLaps = (玩家进度 − AI 进度) / 单圈路点数`。玩家领先越多 AI 越快，落后越多 AI 越慢，但**上限锁在 `aiMul × (1 + catchup)`**。
- **道具决策**（`aiUseItem`）：拿到道具后先握 0.9 秒；龟壳只在目标处于 640px 内且夹角 `|angNorm| < 0.42` 的锥区里才放；香蕉皮在后方威胁（进度差 <40 且距离 <500px）时投；蘑菇/星星/闪电按局势使用。

### 难度表（`DIFFS`）

| 难度 | aiMul（AI 极速倍率） | catchup（橡皮筋强度） | jit（AI 抖动） | scoreMul | timeMul |
|---|---|---|---|---|---|
| 简单 | 0.845 | 0.10 | 1.0 | ×1 | 1.18 |
| 普通 | 0.915 | 0.07 | 0.6 | ×1.5 | 1.06 |
| 困难 | 0.94 | 0.035 | 0.32 | ×2 | 0.97 |

> **平衡红线**：困难档 `aiMul × (1 + catchup) = 0.94 × 1.035 ≈ 0.973 < 1`。这个乘积一旦 ≥1，AI 的橡皮筋上限就会反超玩家巡航极速，玩家（含 Bot）永远拉不开差距、必然被追平。玩家的优势来自漂移迷你涡轮（`BOOST_VMAX = 545` 远高于 AI 巡航），必须给它留出空间。调高困难 AI 时**先算这个乘积**。

## 七、计分与纪录

```
得分 = (名次分 PLACE_PTS[place-1] + 时间奖励) × 难度 scoreMul

PLACE_PTS = [300, 200, 140, 90, 50, 20]   // 第 1~6 名
时间奖励 = max(0, ceil((赛道 par × 3 圈 × timeMul − 完赛时间) × 2))   // 未完赛为 0
```

- 9 格纪录键：`DIFF_ORDER.indexOf(diff) × 3 + trackIdx`，存 `{ score, time }`。
- 只在**新分数更高**时覆盖纪录，但 `time` 字段始终取历史最快（即使这次分数没破纪录）。
- 夺冠（第 1 名）解锁下一条赛道，写 `kart_unlock`。

## 八、确定性

- `startRace` 里 `setSeed(20260928 + trackIdx × 7919 + diffIdx × 104729)`，之后**所有影响玩法的随机**（道具抽取、AI 车道偏移与抖动、装饰物布点、粒子时机）一律走 `rng()`。
- `Math.random` 只用于纯视觉粒子的装饰性抖动，不参与任何判定。
- 固定步长 `STEP = 1/60`，倍速（1x/2x/3x）= 每帧多跑整数个步长，**不改变物理结果**。
- 同种子 + 同输入 → 逐帧快照逐位一致（回归测试里有 hard × 星夜高速 的 Bot 重放断言）。

## 十、音效（Web Audio 实时合成，零音频文件）

### 10.1 引擎循环音

只有零散提示音的赛车「踩下去没反应」，所以引擎音是**持续合成**的：一个锯齿波 + 一个低八度方波（失谐 9 音分）过 lowpass 滤波，参数每帧由 `engineTick()` 用 `setTargetAtTime` 平滑跟随车况。

| 状态 | 基频 | 低通 | 增益 |
|---|---|---|---|
| 起步/怠速（0 px/s） | 44 Hz | 560 | 0.016 |
| 巡航（200 px/s） | ≈90 Hz | ≈1300 | ≈0.054 |
| 极速（400 px/s） | ≈137 Hz | ≈2000 | ≈0.079 |
| 极速 + 加速（boost/星星） | ≈171 Hz | ≈2900 | ≈0.104 |

倒计时期间走怠速音量（0.016）不轰头。`G.scene !== 'race'`、暂停、静音时 `engineStop()` 真正 `stop()` 并丢弃节点；**窗口失焦与切后台也停**——那两处 rAF 会冻结，引擎音就拿不到调音了，不停会留下一个恒定长鸣。

### 10.2 一次性音效（`SFX`）

`select / back / count / go / lap / pickup / boost / drift / shell / bounce / hit / star / thunder / slip / wall / rescue / finish / win / lose / record`。

- `boost`（漂移小喷与蘑菇共用）做成了双层：低频 `150→420Hz` 锯齿铺底 + `320→900Hz` 方波上扫，只有一层时提速感听不出来。
- `rescue` 是脱困回位的一升一降双音提示，配合车身闪烁。

### 10.3 与确定性的关系

音频完全在 `AC` 之上，**不读也不写 `rng()`**；无头测试里 `ensureAC()` 不会被调用（只在真实输入事件里触发），`AC` 保持 `null`，所有 `tone()` 与 `engineTick()` 直接短路返回，因此不影响任何断言。
