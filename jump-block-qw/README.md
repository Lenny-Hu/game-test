# 跳跃方块 Jump Block

模仿微信小游戏「跳一跳」核心玩法的网页版复刻，单文件、零依赖、零外部素材。

> 玩法机制复刻，画面（Canvas 手绘）与音效（WebAudio 合成）100% 原创，不含任何原游戏素材，无版权风险。

## 运行

- 直接双击 `index.html` 用浏览器打开即玩（Chrome / Edge 均可）
- 本地起服务（可选）：`npx serve .` 或任意静态服务器

## 操作

| 动作 | 触屏 | 键盘 |
|------|------|------|
| 蓄力 | 按住屏幕 | 按住空格 |
| 起跳 | 松手 | 松开空格 |

## 规则与计分

- 落在方块顶面任意处：**+1 分**
- 落在方块中心（完美判定）：**+1 + 2×连击数**，即连续完美为 +3 → +5 → +7…
- 直接飞过下一个块落在下下个块：**+2 分**（超远跳）
- 力度太小落回原块：不扣分，连击清零
- 落到块外：跌落，游戏结束，最高分存入浏览器 localStorage（键 `jumpblock-best`）

难度随分数上升：方块尺寸渐小（60→40）、块间距渐大（132→最高约 320）。

## 手感调参

所有核心数值集中在源码 `/* ---------- 数值手感（调这里） ---------- */` 区块：

| 常量 | 默认值 | 作用 |
|------|--------|------|
| `CHARGE_TIME` | 1.15 | 蓄力从 0 到满的秒数（越小越敏感） |
| `RAMP` | 0.1 | 起手防误触延迟（秒） |
| `DIST_MIN` / `DIST_MAX` | 26 / 366 | 跳跃距离区间（逻辑像素） |
| `GAP_MIN` | 132 | 相邻方块中心距下限 |
| `PERFECT_R` | 0.20 | 完美判定的中心半径比例（越大越宽松） |

方块大小/间距随分数成长的曲线在 `makeBlock()` 内：`clamp(60 - score * 0.45, 40, 60)` 与 `clamp(120 + score * 7, 120, 190)`。

## 代码结构

```
index.html
 ├─ <style>      HUD / 遮罩层样式
 ├─ 音效          WebAudio 合成（sfx.charge/jump/land/perfect/fail）
 ├─ 世界生成      makeBlock() 等距双轴随机方块链
 ├─ 落点判定      normDist() 顶面椭圆近似 + land() 结算
 ├─ 输入          pointerdown/up + 空格
 ├─ update()     蓄力 / 抛物线飞行 / 翻转 / 跌落 / 摄像机 / 粒子
 └─ render()     伪等距绘制：方块三面 + 角色 + 特效
```

视角为伪等距（isometric）：方块链沿屏幕右下 / 左下两条轴交替延伸，摄像机平滑跟随。

## 已知限制

- 页面切后台时 `requestAnimationFrame` 暂停，回前台自动继续（正常行为）
- 无存档点，跌落即从零开始（原版如此，故意的）

## 迁移微信小游戏（备选路线）

玩法逻辑可直接平移，需补三件事：
1. **工程壳**：`game.js` 入口 + `wx.createCanvas()` 替换 DOM canvas，触摸事件改 `wx.onTouchStart/End`
2. **合规前置**（个人主体）：软著 1-2 个月（名称一旦登记不可改）、ICP 备案 7-20 个工作日、自审自查报告、隐私保护指引、接入实名防沉迷
3. **变现限制**：个人主体只能接广告（流量主），不能内购
