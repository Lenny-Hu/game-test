本目录下的每个子文件夹是一款独立小游戏，各自自带 index.html 与设计文档。 点下面的卡片进入即可试玩。当前共 0 款。

没有匹配的游戏，换个关键词试试。

怎么跑起来

  • 纯 Canvas 零依赖的游戏（如 jump-block-qw）可以直接双击 index.html 打开。
  • 用到 ES Module / importmap 的游戏（如 jump-block-m3）需要本地静态服务器： cd D:\web\game-test && python -m http.server 5173 或 npx serve .， 再访问 http://localhost:5173。
  • 本导航页用 target="_blank" 打开子目录，两种方式都能正常跳转。

怎么加一款新游戏

  • 在本目录下新建子文件夹，放好 index.html（建议再配一份 README.md）。
  • 在下方脚本的 GAMES 数组里追加一条记录：dir 填子文件夹名，其余字段照注释填写。
