# Combo 累加得分规则

## 规则
- **基础分**：每次跳到新方块 +1
- **正中中心**（accuracy > 0.75）：得分 = `2^combo`（combo 计数从 1 开始）
  - 第 1 次：+2
  - 第 2 次连续：+4
  - 第 3 次连续：+8
  - 第 4 次连续：+16
  - 第 5 次连续：+32
- **贴边但没掉**（0.5 < accuracy ≤ 0.75）：+1，combo 重置为 0
- **几乎掉但还挂住**（accuracy ≤ 0.5）：+1，combo 重置为 0
- **直接掉下去**（无方块可落）：combo 重置为 0，得分不变（之前的 0）

## 反馈
- COMBO 文案持续 1100ms（比之前的 700ms 长，因为 "COMBO x5 +32" 更长）
- combo ≥ 3 时分数字号脉冲放大到 1.5x 180ms；普通 +1 时仍 1.25x 120ms
- 视觉/音效仍按"中心命中"播 perfect + combo 琶音；贴边播 landSafe
