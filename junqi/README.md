# 四国军棋 · Junqi（网页版）

经典四国军棋（陆战棋），纯前端单文件、零依赖、零外部素材。支持 **单人挑战**（你坐南蓝，其余三席电脑）、**双人同盟**（蓝黄两席真人组队对抗绿红两 AI）、**双人对练**（蓝绿两席真人，各带一名 AI 队友）、**电脑演示**（四席全 AI 自战）。电脑棋艺分 **简单 / 普通 / 困难** 三档。

## 怎么跑

- 直接双击 `index.html` 即可（file:// 可用，无需服务器）；
- 或在本仓库根目录起静态服务：`python -m http.server 5173`，访问 `http://localhost:5173/junqi/`。

## 信息模型：明棋

四席共用一块屏幕无法藏子，因此本作采用**明棋**规则：所有棋子的兵种对所有人可见。经典暗棋的"裁判布局 / 摸子试大小"不适用；亮旗机制保留——**司令阵亡后该方军旗位置揭示**（本实现中军旗本即可查看，亮旗作为战报与视觉脉冲提示呈现）。

## 规则（引擎已完整实现）

| 规则 | 说明 |
|------|------|
| 棋子构成 | 每方 25 子：司令 1、军长 1、师长 2、旅长 2、团长 2、营长 2、连长 3、排长 3、工兵 3、炸弹 2、地雷 3、军旗 1 |
| 战斗 | 大衔吃小衔；**同级同归于尽**；**炸弹与任何子同归**；攻入**军旗**则扛旗，旗方全军覆没出局 |
| 地雷 | 只有**工兵**可挖（工兵存活、雷移除）；其余兵种撞雷阵亡、雷不动；地雷与军旗永不移动 |
| 行营 | 每方 5 个，行营内的子**不可被攻击**（进可进、打不能打） |
| 大本营 | 军旗必须摆在两大本营之一；**任何子进入大本营后永久锁定**（含缴获后驻守的敌子） |
| 公路 | 据点间直线相邻走一步；行营与周围八邻另有斜线 |
| 铁路 | 非工兵沿铁路**直线滑行**任意空格（可吃路径上首个敌子，不可隔子跳）；四角弧线视为相邻横/纵线的连续延长段 |
| 工兵 | 铁路沿线**任意转弯**可达（BFS），是唯一的"拆弹挖雷工" |
| 布阵限制 | 地雷限本方最后两排；炸弹不可放第一排（前线）；行营留空 |
| 轮转与阵营 | 南(蓝)→东(绿)→北(黄)→西(红) 逆时针轮转；蓝黄一队 vs 绿红一队，不可吃队友、不可攻击队友行营 |
| 出局 | 军旗被扛，或轮到己无子可动 → 全军覆没出局（子力全部移除） |
| 胜负 | 一队两席皆出局则另一队胜；两队同时不存 → 判和；连续 200 步无吃子判和（`DRAW_LIMIT`） |

操作：菜单选模式与难度开局；真人回合点击己方棋子选中（绿圈 + 可动落点提示，可吃子红圈），点落点走子；触屏与鼠标通用；快捷键 `U` 悔棋、`R` 重开。

## 界面布局（全部画进 Canvas 场景，无侧栏 DOM）

- **棋盘**：129 节点 / 288 边的标准四国军棋盘——四方各 6×5 阵（30 点：23 兵站 + 5 行营 + 2 大本营）+ 中央九宫；公路细线、铁路双实线、四角贝塞尔弧线；行营绿圆、大本营金圈星标；
- **棋子**：军绿圆角方块 + 阵营渐变（蓝/绿/黄/红）+ 兵种名；最后一着连线标记、当前回合方阵中心呼吸圈、亮旗脉冲、大本营锁定子圆点提示、走子滑动动画；
- **右侧信息面板**（横屏 1180×800）：四个座位芯片（你/真人/电脑标签 + 出局置灰 + 在场子数）、悔棋 / 重新开始 / 回菜单 / 音效按钮、电脑棋艺三档胶囊、战绩统计、滚动战报（吃子/同归/扛旗/亮旗全记录）；
- **移动端适配**：窄屏竖屏（≤900px 且高>宽）自动切为 660×1214 竖版——棋盘在上、面板在下，按钮/芯片换行排布；`resize` / `orientationchange` 实时重排，画布按 `devicePixelRatio` 缩放。

## AI 策略

逐手启发式打分（非搜索树），核心构件：

- **威胁图 `enemyThreatMap`**：每回合对每个 AI 席预计算"所有非同盟方可一步/滑行打到某格的最大子"，吃子后若会被更大子报复则大幅扣分；
- **价值表 `VAL`**：工兵 15 → 司令 100，炸弹 40，炸大子划算、炸弹换小子扣分；
- **目标优先级**：能扛旗 → 绝对第一；挖雷加分；同级交换大子换小子扣分；
- **位置倾向**：向前推进（向敌方阵营方向）每格加分、行营歇脚加分、避免进入本方大本营焊死；
- **随机扰动**：打分叠加噪声、在最优容差池内随机择一，保证 replay 多样性。

### 电脑棋艺三档（菜单胶囊切换，localStorage 键 `junqi-diff`）

| 档位 | 噪声 | 择着容差 | 思考延时 | 说明 |
|------|------|---------|---------|------|
| 简单 | 60 | 无限 | 420ms | 半随机（50% 概率随机吃子），适合入门 |
| 普通（默认） | 22 | 28 | 460ms | 完整威胁评估 + 位置倾向 |
| 困难 | 6 | 3 | 520ms | 近贪心最优：额外启用移动躲吃评估 |

## 代码结构（index.html 内单脚本）

1. 常量与裁判：`PIECE_COUNTS / VAL / combat / teamOf`；
2. 拓扑构建：`NODES / NEIGH / EDGES / RAIL_LINES`（4 条跨中央贯通线 + 16 条本阵短线 + 4 条角弧并线）；
3. 布阵：`LAYOUT_SLOTS / randomLayout`（旗入大本营、雷限后两排、弹离前线的约束随机）；
4. 走法生成：`legalMoves = roadStep(公路+行营斜线) + railSlide(非工兵直线滑行) + railBfs(工兵转弯)`；
5. 对局流程：`startMatch / applyMove / eliminate / advanceTurn / setOver / doUndo`（快照制悔棋，跨 AI 手回退）；
6. AI：`enemyThreatMap / aiScoreMove / aiChoose / stepAiTurn`；
7. 渲染：`drawEdges / drawNodes / drawPieces / drawMarkers / drawPanel / drawMenu / drawOver`；
8. 输入：`evPos / hitButton / nodeAt / onDown`（pointer 事件 + 键盘快捷键）。
