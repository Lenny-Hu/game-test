# 大富翁（强手棋）· Monopoly

单文件、零依赖、纯 Canvas 2D 的大富翁网页版。支持 **2~4 个座位**：1~4 名真人玩家在
同一个页面（同屏/热座）轮流操作，剩余座位全部由电脑 AI 补足；也支持全电脑自战演示。
所有游戏内 UI（座位信息卡、骰子盘、按钮、弹窗、资产簿）都画进 Canvas 场景内，
手机竖屏自动切换为「棋盘在上、面板在下」的竖版布局。

- 入口：直接用浏览器打开 `index.html`（无需服务器、无任何外部请求）
- 音效：Web Audio 实时合成（无音频文件），菜单或顶栏可静音

## 规则实现

### 棋盘（40 格）
| 类别 | 数量 | 说明 |
|------|------|------|
| 地产街道 | 22 处 / 8 色组 | 棕 2、浅蓝 3、粉 3、橙 3、红 3、黄 3、绿 3、深蓝 2 |
| 铁路 | 4 条 | 华北 / 华东 / 西南 / 华南，持 1~4 条收租 25/50/100/200 |
| 公用事业 | 2 处 | 电力公司 / 自来水厂，租 = 对方骰点 ×4（两家全持 ×10） |
| 卡牌格 | 机会 3 + 公益金 3 | 两组卡组各 16 张，抽完轮放回环 |
| 税 | 2 处 | 所得税 ¥200、奢侈税 ¥100 |
| 功能格 | 起点 / 监狱 / 免费停车 / 进监狱 | 经过起点领 ¥200（停在起点不双发） |

### 回合流程
1. 双骰行进；**掷出对子可再掷一次**，连续三个对子直接入狱。
2. 落在无主地产/铁路/公用事业：现金足够可按下标价购买（真人弹窗决策，AI 自动决策）。
3. 落在他人地产：缴租。同组地产集齐且未盖房时**空地租金翻倍**；盖房后按租金表收租。
4. 落在机会/公益金：抽卡并立即结算（前进/后退、入狱、收付款、出狱自由卡等）。
5. 落在「进监狱」：直接移到监狱格（不经过起点、不领薪水）。

### 监狱
入狱后最多尝试掷 3 次对子；也可以：
- 使用「出狱自由卡」（机会/公益金各含 1 张，可囤）；
- 缴纳 ¥50 保释金（第 3 次仍失败会自动代缴并前进）。
掷对子出狱后按点数前进，且因是对子可继续再掷。

### 建造 / 抵押
- 集齐同色组（组内无抵押）后可**均匀盖房**：只能建在组内房数最少的地上，最多 4 房，
  第 5 级为旅馆；售房同样按均匀规则倒序拆除。
- 抵押：组内无房时可抵押地产获得抵押价（约半价）；赎回付抵押价 ×1.1（上取整）。
- 抵押中的地产不收租，也不能盖房；点击棋盘任意格可查看地契详情并直接操作。

### 破产与胜负
- 玩家现金不足支付时，系统自动按「拆房 → 抵押」顺序变现补款；
  仍不足即宣告破产：资产全部移交债权人（欠银行则收回重新发售）。
- 只剩一家未破产即获胜；**满 120 轮**按总身家（现金+地产评估值）判定胜者。

### 与官方桌游的差异（简化说明）
- 放弃认购时**不举办公开拍卖**，地产留给后来人（数字版大富翁常见规则）；
- 欠缴时由系统自动变现，不需要玩家手动逐笔抵押（也可在破产前自己提前整理资产）；
- 无「以物抵债」协商、无三世界方块/土地 deeds 交易界面；监狱访问格无特殊奖励。

## AI 策略

- **购地**：优先凑齐同色组（能集组必买）；无竞争时囤组；有竞争时中低价抢地段；
  保留最低生活金 ¥80，铁路看持有数加减码。
- **建造**：回合开始前检查整组垄断的地产，在保留 ¥240 安全垫的前提下逐步盖房（封顶 3 房）。
- **监狱**：现金紧张时用出狱卡；否则赌对子，最后一次自动缴保释。

真人玩家可随时通过「我的资产」地契簿或点击棋盘格进行建造/售房/抵押/赎回，
操作范围与合法性由 `canBuild / canSellHouse / canMort / canUnmort` 统一裁决。

## 代码结构（index.html 单文件三段）

| 区块 | 内容 |
|------|------|
| 规则引擎 | 棋盘/卡组数据、`newGame / advance / landOn / rentOf / payTo / bankrupt`、虚拟时钟定时器（`schedule / pump / pumpFast`，无头可瞬发）、AI（`aiAct / aiWantsBuy / aiBuildPlan`） |
| 渲染层 | `computeLayout`（横/竖屏两套布局）、`drawBoard`（40 格 + 房子/抵押标记 + 中央骰子盘）、玩家卡、按钮热区（即时模式 `HOT`）、购买弹窗 / 地契簿 / 格详情 / 卡牌横幅 / 终局榜 |
| 事件层 | `pointerdown` 命中按钮或棋盘格、滚轮翻消息记录（新消息自动滚到最新一条）、快捷键（空格=掷骰/结束，Enter/Delete=买/弃，Esc=关弹窗，M=静音）、`requestAnimationFrame` 主循环 |

回合状态机：`roll → anim（移动/结算）→ buy?（购买弹窗）→ again/end →（下一位）`，
真人席位等待点击，AI 席位由定时器驱动（点「⏩ 快进」可立即清空动画队列）。

## 无头回归测试

```bash
node _test.js
```

桩掉 DOM/Canvas 后 eval 页面脚本，约 250 项断言覆盖：

1. 棋盘数据完整性（40 格 / 28 可拥有 / 组大小 / 租金表递增）；
2. 全 AI 4 人自战整局跑通并产生胜者；
3. 租金计算（垄断翻倍、房屋档位、铁路阶梯、公用 ×4/×10、双倍租金卡、抵押免租）；
4. 移动、经过起点薪水、后退、直达类卡牌不重复触发落地；
5. 入狱 / 保释扣款 / 出狱续链；
6. 均匀建造与「组内有房禁抵押」规则、建造/售房/抵押现金流、赎回价；
7. 欠缴自动变现、破产移交债权人、欠银行收回银行；
8. 卡牌效果抽样与抽卡后续接；
9. 全真人 3 人局用 `skipPending` 无人值守推进到终局；
10. 120 轮时限按身家判定。

## 手机竖屏

视口高>宽时自动切竖版：画布逻辑尺寸 470×994，棋盘 446 在上，
玩家卡（2×2）、操作按钮、消息记录在下方依次排列，全部触摸可点。
