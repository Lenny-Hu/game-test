# 黄金矿工 · Gold Miner H5

单文件 Canvas 2D 网页版黄金矿工，零外部依赖、零图片资源，金块/岩石/钻石/神秘袋/炸药、井架矿工与云层全部程序化绘制，音效 Web Audio 实时合成。双击 `index.html` 即可玩，画面天然竖版（矿井纵向），手机竖屏直接适配。

## 玩法规则

- 爪钩用绳子挂在井架天轮滑轮上（绳自吊环绕过滑轮接至矿工绞盘卷筒），在井口下方左右摆荡（±57°），**点击/空格放出**；待机时三齿张开探物，碰到物**三齿合拢夹住**往回收，**越重收得越慢**；收爪途中再点一次可**脱手**丢物（常用来自救甩炸弹）。
- **矿物表**（面值 / 重量，收爪速度 = 560×绞盘倍率 ÷ 重量）：

| 矿物 | 面值 | 重量 | 备注 |
|---|---|---|---|
| 大金块 | $500 | 3.8 | 埋得深、拉得慢 |
| 中金块 | $250 | 2.35 | — |
| 小金块 | $100 | 1.2 | 轻快，苍蝇腿也是肉 |
| 大岩石 | $20 | 5.2 | 全场最重，纯时间黑洞 |
| 小石块 | $11 | 3.2 | — |
| 钻石 | $600 | 0.9 | 最贵最轻，只埋最深层 |
| 神秘袋 | $60~450 | 3.0 | 抓住瞬间才开价（10 元一档） |
| 炸药 | — | 4.0 | 第 2 关起出现；拉回井口**爆炸扣 5 秒**并僵直摆爪 0.9 秒，半路脱手则原地炸掉无害 |

- **关卡目标线（累计钱数）**：共 5 关，时间到时 `现有钱 ≥ 目标` 即过关进商店，否则本局结束；过关后钱与升级**携带**进下一关，计时重置。
- **收尾宽限**：计时归零瞬间不清场——正在收的最后一爪照常入账再判定（正在收超重的大石时留个心）。
- **三档难度**：只改目标线与限时，矿物面值一致；**最佳成绩按难度分别记录**（口径为本局累计所得，不受购物扣钱影响）。

| 难度 | 目标 | 每关限时 |
|---|---|---|
| 简单 | ×0.85（450/1300/2400/3850/5800） | 75 秒 |
| 普通 | ×1.0（500/1500/2800/4500/6800） | 60 秒 |
| 困难 | ×1.2（600/1800/3350/5400/8150） | 50 秒 |

- **局间商店**（每级三档价，钱不够就别买）：

| 升级 | 效果 | 三档价格 |
|---|---|---|
| 强力绞盘 | 收爪速度每级 +35% | 400 / 700 / 1100 |
| 磁力爪 | 抓取半径每级 +45% | 300 / 550 / 900 |
| 碎岩锤 | 碰到岩石直接砸碎继续放爪（30% → 60% → 100%） | 500 / 800 / 1300 |

- 难度选择与各难度最佳纪录存 `localStorage`（键 `goldminer.diff.v1` / `goldminer.best.v1`）。

## 操作

- **鼠标/触屏**：点屏幕空白处（或按钮以外区域）放爪；收爪途中再点 = 脱手。
- **键盘**：`空格/Enter` 放爪；菜单 `1/2/3` 切难度、`Enter` 开始；`Esc` 暂停，`M` 静音。
- 菜单、HUD、商店、结算面板全部画在 Canvas 场景内，按钮均为帧内热区命中判定。

## 技术要点

- **固定步长**：物理以 1/120s 步进（帧内累加器补步），放爪 820px/s、空爪回收 1500px/s、带物 560/重量，均为逻辑像素×缩放 `S`。
- **矿图生成**：620×660「设计空间」内拒绝采样摆放（间距含半径与抖动），再等比映射进任意窗口高度的可视矿脉——**任何屏幕尺寸都不重叠、不越界**；每关布局用 `mulberry32(关卡+难度+本局随机盐)` 播种，同局可复现，测试可断言确定性。
- **价值梯度埋深**：每种矿有各自的深度带（钻石/炸药只在深层，小金块全层撒），大目标迫使爪钩深入，摆动角的余弦误差让深层命中更难。
- **摆动模型**：角度匀速往返于 ±1.0rad（≈57°），边界折返；摆幅与绳长配合使爪在两端极限仍低于滑轮、不扫井架。爆炸僵直只冻结摆爪不影响收爪。
- **绳路与夹爪**：绳分三段程序化绘制——爪吊环 → 沿滑轮外缘包弧 → 绞盘卷筒，爪体沿绳方向对齐（随摆角镜像旋转）；夹合度 `G.claw` 以指数缓动追踪（抓到瞬间从 0.25 快速合齿至 1，脱手回张开），被夹物品沿爪轴悬挂并向爪心收拢，画在齿下层形成"包住"效果。
- 音频：Web Audio 实时合成——放爪下滑音、抓取闷响（音高随重量）、金币琶音（音数随面值）、砸石噪声、爆炸低频轰鸣、过关四音 fanfare、读秒滴答，无音频文件。
- 特效：金块微光闪烁、钻石星芒、炸药引信火花、爆炸火花粒子、金币爆花、得分飘字、爆炸震屏。
