# 中国象棋 · Xiangqi（网页版）

经典中国象棋，纯前端单文件、零依赖、零外部素材。支持 **双人同屏**（两位真人轮流在同一页面走子）、**单人对战 AI**（可选执红先行或执黑后行，AI 棋艺分 **简单 / 普通 / 困难** 三档），任意空位由电脑玩家接管；另有 **电脑自战演示** 模式。

## 怎么跑

- 直接双击 `index.html` 即可（file:// 可用，无需服务器）；
- 或在本仓库根目录起静态服务：`python -m http.server 5173`，访问 `http://localhost:5173/chinese-chess/`。

## 规则（引擎已完整实现）

| 规则 | 说明 |
|------|------|
| 車 | 横竖直线任意格，遇子 Blocking |
| 馬 | 走「日」，前进方向紧贴点有子则**蹩马腿** |
| 炮 | 平移同車；**吃子须隔一个炮架**跳吃 |
| 象 | 走「田」字，**不可过河**，田心有子则**塞象眼** |
| 士 | 九宫内斜走一格 |
| 帥 / 將 | 九宫内直走一格；**双王不可照面**（同列中间无子即判送将，非法） |
| 兵 / 卒 | 过河前只许直进，过河后可直进或横移一步，永不后退 |
| 将军 | 走子后对方将/帅被攻击即将军，界面红色脉冲提示 |
| 胜负 | **绝杀**（被将且无合法应将）或**困毙**（轮到方无合法着法）判负；和棋为 120 步自然限着或双方攻势子力（車/炮/兵）耗尽后 60 步无吃子 |

操作：真人回合点击己方棋子选中（金色光圈），棋盘显示绿色落点（可吃子为红圈），点落点走子；最近一着以绿色角标标记起点/终点。触屏与鼠标通用。

## 界面布局（全部画进 Canvas 场景，无侧栏 DOM）

- **左侧棋盘**：木纹棋盘、九宫斜线、楚河汉界、炮位/兵位星标、棋子（渐变立体圆棋 + 楷体字）、选中光环、落点提示、将/帅受攻红色脉冲、走子滑动动画；
- **右侧信息面板**（同一 Canvas 内绘制）：当前回合卡片（将/帅头像 + 真人/电脑/思考深度状态）、绝杀/困毙/和棋结果、将军闪烁、双方损失子力墙（缩略棋子每行 12 枚、超出自动换第二行，不会溢出面板）、双列着法记录（红黑各用中文/数字纵线记谱）、悔棋 / 重新开始 / 返回菜单 / 音效开关按钮；
- 顶栏模式菜单（含「电脑棋艺」难度切换按钮组，当前档位高亮反色）、胜负弹窗均为 Canvas 覆盖层，按钮带悬停高亮；
- **移动端适配**：窄屏竖屏（≤900px 且高>宽）自动切换为竖版布局（设计尺寸 680×1180）——棋盘占顶部、信息面板横置于底部（损失墙单行排布、着法记录 7 行、按钮 2×2），横屏/桌面保持 1180×790 侧栏布局；`resize` / `orientationchange` 实时重排，画布按 `devicePixelRatio` 正确缩放（高分屏不发糊、不错位），触摸走子与鼠标共用一套坐标映射。

## AI 策略

`negamax + α-β 剪枝`，配合：

- **静态搜索（quiescence）**：叶子节点延伸吃子序列，避免"水平线效应"送子；
- **迭代加深 + 限时**：每层单独一次 tick（不冻结界面），受单层 `BUDGET_PER_DEPTH` 与总 `TOTAL_BUDGET` 双重预算约束，超时用上一层最佳着法；
- **评估函数**：子力价值 + 位置价值表（PST，各兵种 9×10 表，黑方镜像），兵随过河/逼近底线递增，馬/炮/車偏中心与前压；
- **着法排序**：吃子按 MVV-LVA 优先 + 上一层 PV 顺序；
- **终局随机**：在距最优一定分差内的准最佳着法中随机择一，增加对局多样性。

### 电脑棋艺三档（菜单顶部「电脑棋艺」切换，人机与演示局生效）

| 档位 | 最大深度 | 单层预算 | 总预算 | 择着容差 | 说明 |
|------|---------|---------|--------|---------|------|
| 简单 | 2 | 150ms | 400ms | ≤120 分 | 浅搜 + 大随机，几乎随手，适合入门 |
| 普通 | 4 | 450ms | 1200ms | ≤30 分 | 中等，思考约 0.5s/步 |
| 困难（默认） | 7 | 1200ms | 4000ms | ≤5 分 | 深搜近最优，实测约 1.8s/步 |

档位写入 `localStorage`（键 `xiangqi-diff`）持久化，下次进入自动恢复；面板标题旁会显示当前模式与难度（如「人机 · 你执红 · 困难」）。测试用 `_test.js` 直接覆写 `BUDGET_PER_DEPTH / MAX_DEPTH` 全局量跑快速档，不受档位影响。

## 代码结构（index.html 内单脚本）

1. 引擎层（纯函数，可无头测试）：`newBoard / genPseudo / attacked / inCheck / legalMoves / perft`；
2. 评估与搜索：`VAL / PST / evalRed / negamax / quiesce / rootSearch`；
3. AI 步进：`aiStep / aiFinish`（迭代加深调度 + 着法池随机）；
4. 记谱：`notation`（红用汉字纵线、黑用阿拉伯数字，进/退/平）；
5. 对局流程：`startMatch / applyMove / doUndo / maybeAi`；
6. 渲染：`drawBoardScene / drawPiecesLayer / drawPanel / drawMenu / drawOver`；
7. 输入与主循环：`onDown / update / frame`。
